# Vue 3 是什么

> **学习目标**：声明式渲染、组件化与两种 API 风格。约 14 分钟。本文依据 Vue 3 官方指南组织，用独立示例和练习讲清用法；右侧源码是进一步深入的关联入口。

## 一、概念与适用场景

Vue 使用声明式模板描述 UI，根据响应式状态的变化更新页面。组件把可复用的视图和行为封装成独立单元。Vue 3 同时支持 Options API 和 Composition API；本课程以 Composition API + `<script setup>` 为主，并在需要时对照 Options API。

记住三个概念：**状态**决定显示什么；**模板**描述如何显示；**组件**组织独立功能。Vue 不要求所有项目都写成 SPA，也可以在已有页面中渐进引入。

## 二、动手示例

以下代码用于演示本节要点。多文件片段请按照注释拆分到不同文件；项目使用 Vue 3.5 系列。

```vue
<script setup>
import { ref } from 'vue'
const count = ref(0)
</script>

<template>
  <button @click="count++">点击 {{ count }} 次</button>
</template>
```

**试着分析**：这里的输入由谁持有？执行什么动作后发生变化？页面或子组件如何接收到变化？能否在不改变数据所有权的前提下完成需求？

## 三、常见问题与边界

模板中 ref 会自动解包，脚本中修改时仍使用 `count.value++`。不要把模板的自动解包规则照搬到普通 JS。

建议先观察浏览器运行结果，再通过 Vue Devtools 检查对应组件的状态变化，区分组件传值、代理响应式和 DOM 更新三种不同层次的问题。

## 四、动手练习

1. 将按钮改成减法器，并增加一个 `<p>` 显示计数是否大于 5。
2. 预测示例在一次状态变化后的显示结果，实际运行后检查预期；对比异常情况时重点检查模板绑定、数据引用和生命周期。
3. 尝试把示例封装成独立的 `.vue` 组件，写清对外输入与事件（如果本节是构建或测试课程，则整理出运行命令及结果）。
